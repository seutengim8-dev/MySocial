# MySocial 4.0 — 독립형 SNS

원본 MySocial의 다크 테마, M 로고, 왼쪽 아이콘 레일, 사용자/최근 대화 사이드바, 채팅 패널, 프로필·그룹·릴스 화면 구성을 참고해 Supabase 없이 Express와 로컬 JSON 저장소로 재구성했습니다.

## 실행
1. 이 폴더를 VS Code에서 엽니다.
2. 터미널에서 `npm.cmd install`
3. `npm.cmd start`
4. `http://localhost:3000` 접속

## 4.0 변경 사항
- 기존 3.0의 화면과 기능을 유지하면서 메시지 수정 기능 추가(전송 후 15분 이내)
- 음성 통화 생성 시 누락된 상태값 오류 수정
- 그룹 채팅과 나와의 채팅도 주기적으로 새 메시지 갱신
- 메시지 첨부 파일 경로 검증 및 통화 신호 데이터 검증 강화
- 프로덕션 환경에서 HTTPS 쿠키 설정 지원

## 구현된 기능
회원가입/로그인(bcrypt 해시), 프로필 이름·소개·이모지 수정, 사용자 목록, 1:1 메시지/읽음 표시/삭제/이모지 반응, 친구 요청 생성 API, 그룹 생성 및 그룹 메시지, 이미지 업로드, 릴스 업로드·좋아요, 차단·신고 API.

## 아직 이식되지 않은 원본 기능
음성 통화(WebRTC), 완전한 실시간 Presence/타이핑, 나와의 채팅 서버 저장, 친구 요청 수락/거절 UI, 운영자 관리 화면, 알림음·바탕화면 알림 설정은 아직 구현되지 않았습니다. 새 메시지는 2.5초 간격으로 확인합니다.

## 저장 위치
계정·메시지·친구·그룹·신고·릴스 메타데이터는 `data/`의 JSON 파일, 업로드 파일은 `public/uploads/`에 저장됩니다. 이 폴더들은 백업하세요. 현재는 로컬 테스트용이며 공개 배포 전 SESSION_SECRET 환경 변수 설정, 영구 세션 저장소, HTTPS, 업로드 제한 및 백업 정책을 추가로 점검해야 합니다.

## 추가 기능: 음성 통화
- 사용자 간 WebRTC 음성 통화, 수신 확인, 음소거, 통화 종료
- 온라인 상태 heartbeat API
- 마이크 권한이 필요하며 localhost 또는 HTTPS에서 사용해야 합니다.
- 일부 네트워크에서는 TURN 서버가 없어 통화 연결이 실패할 수 있습니다. 인터넷 공개 배포 시 TURN 및 보안 설정이 필요합니다.

## MySocial 3.0 추가
- 온라인/오프라인 상태 표시(heartbeat)
- 받은 친구 요청 수락/거절 및 친구 목록
- 나와의 채팅을 서버의 개인 메모로 저장
- 브라우저 새 메시지 알림(🔔 버튼에서 권한 허용)


## 4.0 실행 참고
Windows PowerShell에서는 `npm.cmd install` 후 `npm.cmd start`를 실행해도 됩니다. `data/`와 `public/uploads/`는 사용자 데이터이므로 삭제하지 마세요.
